### 문제 - <code>숫자의 표현</code>

### 알고리즘 설계

### 풀이 코드

```jsx
function solution(n) {
  let cnt = 0;
  while (n !== 0) {
    if (n % 2 !== 0) {
      n = Math.floor(n / 2);
      cnt++;
    } else {
      n = n / 2;
    }
  }
  return cnt;
}
```
